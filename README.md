# Branson Rose — Personal Site

## Overview

A responsive personal portfolio showcasing my projects, technical skills, certifications, and professional background. Built with React, TypeScript, and Vite, with an emphasis on accessibility, reusable components, responsive design, and clean visual presentation.

---

## Tech

- React
- TypeScript
- Vite
- HTML5
- CSS3

---

## What I Built

- Rebuilt the portfolio as a component-based React application
- Responsive layout optimized for desktop, tablet, and mobile devices
- Modern landing section with professional headshot
- Reusable components for projects, skills, certifications, and site sections
- Project showcase with direct GitHub repository links
- Skills and professional certifications sections
- Semantic HTML for accessibility and SEO
- Keyboard-accessible navigation
- Custom responsive CSS with consistent typography, spacing, and visual design
- Dynamic copyright year using JavaScript
- Accessible navigation with skip-to-content functionality

---

## Future Development

This site will continue to evolve beyond the main portfolio. Future updates will introduce additional pages and resources, including landing page templates, project showcases, and other web development examples.

The goal is to gradually turn the site into both a personal portfolio and a collection of reusable design and development work that demonstrates different approaches to building modern web experiences.

- Converting a static HTML/CSS website into a component-based React application
- Structuring React applications using reusable components

- Improving accessibility through semantic markup and keyboard navigation
- Organizing CSS for maintainability and scalability

- Balancing visual polish with performance and simplicity
- Designing a portfolio that effectively presents technical skills and projects
